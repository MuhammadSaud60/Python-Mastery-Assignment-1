# Assignment 1
## FILES
`part01`–`part12` and `school_tools.py` contain the Python exercises; root `test_*.py` files test selected exercises.
## PROJECT
`final project/` is the integrated School Manager; run `python main.py` from that folder.
## TESTS
Run `python -m pytest -q` inside `final project/` for its tests, or from this folder use `python -m pytest -q test_grades.py test_bank_account.py` for exercise tests.
